# Prompt — Implement One Feature

Dùng Skill phù hợp. Triển khai duy nhất `FEAT-XXX` (thay bằng ID thực tế).
Đọc AGENTS.md, SPEC, BUSINESS_RULES, ARCHITECTURE, API/DB docs và dependencies của Feature.
Trước khi code: nêu mục tiêu, dependencies, files sẽ tạo/sửa và test plan. Sau đó implement nhỏ, thêm tests, chạy build/tests thực tế. Không sửa Feature khác ngoài dependency cần thiết. Không mark completed khi thiếu test evidence. Cập nhật feature_list.json, progress.md, implementation_log.md và docs liên quan. Giải thích bằng tiếng Việt, ghi lệnh PowerShell và đường dẫn file.
