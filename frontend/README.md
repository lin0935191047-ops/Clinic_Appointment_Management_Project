# Frontend (React.js Application)

Thư mục này được dành riêng cho mã nguồn giao diện người dùng xây dựng trên **React 18+**, **TypeScript**, **Tailwind CSS** và **TanStack Query**:

- `src/features/`: Các mô-đun chức năng độc lập (`auth`, `booking`, `doctors`, `appointments`, `reception`, `admin`).
- `src/components/`: UI components dùng chung (Buttons, Modals, Form Inputs, Tables, Alerts).
- `src/hooks/`: Custom hooks tái sử dụng.
- `src/services/`: Cấu hình API Client, Interceptors, Token management.
- `src/types/`: Định nghĩa kiểu dữ liệu TypeScript dùng chung.

> Sẽ được khởi tạo chi tiết trong **Phase 4** theo kế hoạch tại [docs/DEVELOPMENT_PLAN.md](../docs/DEVELOPMENT_PLAN.md).
